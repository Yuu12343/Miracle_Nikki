# 奇迹暖暖
因为奇迹暖暖玩久了，没什么灵感，我就做了这个随机抽取衣柜里的1-2件衣服，把它搭配完整

数据来源于数据来自玩家社区整理（奇迹暖暖Wiki，以及奇暖搭配器等）

最好在电脑上面用，手机自带浏览器可能会卡

非要在手机上面用的话，就先把它存到「文件」里，再用 Chrome / Safari / Edge 打开。

■ 「抽核心部件」：抽取 1–2 件必须用上的衣服（含部位/编号/套装/来源/属性），围绕它搭全身。
  可以按部位筛（只想抽裙子就点掉别的），也能限星级。
· 「抽主题」：随机给一个搭配主题，附带搭配提示。
· 「灵感套餐」：部件 + 主题 + 一条限制条件（比如「必须穿外套并且敞开穿」），卡壳时最好用。
· 电脑上按空格＝再抽一次；「复制结果」可以把这轮抽到的文字复制走。

■ 要不要导入自己的衣柜（可选）
· 不导入也能用：会从全部 3.7 万件单品里抽。
· 衣柜只存在你自己那台设备的浏览器里，不会跟着文件传出去；
  换手机 / 换浏览器要重新导入一次（可以用「导出编号」备份，再在新设备导入）。

■ 其它
· 单品图片是联网取的，断网就只有文字没有图。
· 目前收录到 2026/10/4 出的衣服，之后新出的没有；
  编号对不上时会提示「N 个编号库里没有」，不是你没导入成功。
